Windows 11でWi-Fiにつながらないときに試すこと

WindowsのWi-Fiトラブルは、無線LANのオン・オフ、接続先の選択、ネットワーク診断から進めると原因を整理できます。

読了目安 約4分 · 記事更新：2026-10-17
結論：まず、ここから確認
  • タスクバーでWi-Fi接続状態を確認
  • Windowsのネットワーク診断を利用
  • ほかの端末の接続可否で原因を切り分ける

公式資料照合：2026-10-17。実機検証：未実施。対象・確認の限界：Windows 11の基本的なWi-Fi確認。ドライバー削除・初期化・管理PCの設定変更は案内しない。 公式資料との照合です。実機・全型番・全OS版での動作確認は未実施です。

症状別の原因と次の確認

Wi-Fi自体につながらない

Wi-Fiと機内モード、ネットワーク選択を確認します。

接続済みでもネットが使えない

回線・アプリ等の問題も候補です。表示だけで故障は確定できません。

STEP BY STEP

まず試したい手順

設定を大きく変える前に、簡単に試せる項目から順に見ていきましょう。確認した項目にチェックを付けると、進捗を記録できます。

確認の進み具合0 / 4 件確認

チェックした内容は、この端末のブラウザにだけ保存されます。

01

Wi-Fiがオンか確認する

タスクバーのネットワークアイコンを開き、Wi-Fiがオンになっているかを確認します。機内モードも確認しましょう。

02

正しいネットワークを選ぶ

接続したいネットワーク名が一覧にあるか確認し、必要に応じてパスワードを入力し直します。

03

Windows 11の自動診断を使う

Microsoft公式ページのWindows 11向け「問い合わせ（Get Help）」アプリのネットワーク診断を開き、画面の指示に従います。Windows 10向けの「状態」画面と混同しないでください。アプリが使えない場合は公式の一般的な確認手順へ進みます。

04

別の機器と比べる

スマホでもWi-Fiを使えない場合はルーター・回線側の可能性があります。パソコンだけならアダプターやWindows設定を中心に確認します。

IF IT STILL DOESN’T WORK

それでも改善しない場合

業務用PCは管理者に相談します。個人用PCでもドライバー削除・ネットワーク初期化はこのガイドでは案内しません。端末型番、Windows版、エラー、他機器の接続可否を控えてPCメーカーや回線事業者へ相談してください。

機種やOSのバージョンによって画面や操作手順が異なります。解決しない場合は、メーカーの公式サポートで型番に合う案内を確認してください。

FAQ

よくある質問

Wi-Fiボタンが表示されない場合は？

無線LANアダプターの状態やドライバーなどが関係することがあります。Microsoft公式の詳細手順で確認してください。

『インターネットなし』と表示される場合は？

Wi-Fiには接続できていても外部ネットワークに到達できていない状態の可能性があります。別端末でも確認すると切り分けやすくなります。
